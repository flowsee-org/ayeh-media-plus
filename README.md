# Ayeh Media Plus (آیه پلاس)

سامانه چندرسانه‌ای تدبّر در قرآن کریم، آموزش، ارتباط با اساتید و مسابقات قرآنی.

## ویژگی‌ها (Features)

- **قرآن کریم و تفسیر موضوعی**: مطالعه مصحف شریف، ترجمه، تفسیر المیزان و نمونه، صوت قاریان برجسته، و تحلیل کلمات.
- **شبکه اجتماعی و تدبّر**: امکان ارسال پست، یادداشت‌های تدبّری، استوری و گفتگو پیرامون آیات.
- **پخش زنده اساتید (Live Streaming & WebRTC)**: پخش زنده جلسات تفسیر و پاسخ به شبهات به همراه چت زنده.
- **دستیار هوش مصنوعی قرآنی (AI Assistant)**: راهنمای هوشمند تدبّر و معرفی آیات متناسب با احوال و دغدغه‌های کاربر.
- **مسابقات و پویش‌ها**: شرکت در مسابقات تلاوت و ثبت رای.
- **مجموعه‌های مطالعاتی**: ساخت و اشتراک‌گذاری دسته‌بندی‌های اختصاصی از آیات.

## پیش‌نیازها و نصب (Setup)

1. نصب وابستگی‌ها با pnpm:
```bash
pnpm install
```

2. ایجاد و همگام‌سازی پایگاه‌داده SQLite:
```bash
pnpm exec prisma db push --schema=server/prisma/schema.prisma
```

3. بارگذاری داده‌های اولیه (کاربر مدیر، اساتید، آیات منتخب، موضوعات):
```bash
pnpm seed
```

## اجرای برنامه (Running Locally)

برای اجرای هم‌زمان فرانت‌اند (پورت ۵۱۷۳) و بک‌اند (پورت ۵۰۰۰):

```bash
pnpm dev
```

- آدرس برنامه در مرورگر: `http://localhost:5173`
- حساب کاربری پیش‌فرض مدیر:

## معماری سامانه (Architecture & Rendering Patterns)

- **Package Manager**: `pnpm` با ساختار hoisted بهینه‌شده.
- **Frontend**: Next.js 15 (App Router), React 19, Tailwind CSS, Radix UI, Lucide Icons, Socket.io-client.
  - **SSG (تولید استاتیک زمان بیلد)**: آیات منتخب، فهرست موضوعات، فهرست قرآن.
  - **ISR (بازسازی افزایشی پس‌زمینه)**: صفحات اساتید (`revalidate: 1h`)، مجموعه‌ها (`revalidate: 30m`)، آیات (`revalidate: 1d`).
  - **SSR (رندر سمت سرور پویا)**: صفحه اصلی (خانه)، فید جامعه و پست‌های زنده.
  - **CSR (رندر سمت کلاینت)**: پخش زنده و وب‌آرتی‌سی، استودیو کارت، دستیار هوش مصنوعی، پنل مدیریت، احراز هویت.
- **Backend**: Node.js, Express, Socket.io (WebRTC signaling & presence), Multer.
- **Database & ORM**: SQLite (`dev.db`) با Prisma ORM.
- **AI Integration**: پشتیبانی از OpenAI، Google Gemini یا حالت هوشمند آفلاین.
